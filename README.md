# ppt-course-notes / PPT 自动生成课程笔记 Skill

一个用于 **依据实际上传的 PPT、PDF、图片和教材资料，按课程章节顺序直接在对话框中生成详细中文课堂笔记** 的 Skill。它面向需要系统整理课程知识点的高校学生与授课辅助人员，主要接收PPTX、PDF、课件截图、课程 ZIP、教师要求和选配的教材/课堂录音转写，按照先忠实覆盖原课件，再讲清概念、条件、公式、推导、例题和易错点进行处理，并输出当前对话中的完整中文课程笔记（默认不创建新文件）。

Skill 标识：`ppt-course-notes`

> **特别说明：**不凭文件名推断未读的课件内容；不能保证自动识别所有扫描公式、图片和电路数值；默认不创建笔记文件，也不替代教师教材。

## 2. Skill 简介


面向高校课程笔记整理；把单纯的课件摘要扩展为按原始顺序可自学的知识点讲义，保留课件页码与原题出处。作者：15723209543@163.com。

### 2.1 适用场景


（1）按 PPT 原顺序整理高等数学、概率论、离散数学与电路课程；（2）整理 Java/C++ 语法与代码例题；（3）合并同章多份 PPT 并标记来源；（4）结合教师补充材料重整同一节笔记。

### 2.2 不适用场景与能力边界


不凭文件名推断未读的课件内容；不能保证自动识别所有扫描公式、图片和电路数值；默认不创建笔记文件，也不替代教师教材。

## 3. 安装方法


### 3.1 本地或用户级安装


Windows：仓库创建并推送后运行 `git clone https://github.com/15723209543/ppt-course-notes-AIskill.git`，进入 `ppt-course-notes-AIskill` 执行 `./install.ps1`；或把内层 `ppt-course-notes`（包含 SKILL.md）复制到 `%USERPROFILE%\.codex\skills\ppt-course-notes`。macOS/Linux：将内层 `ppt-course-notes/` 复制到 `$HOME/.codex/skills/`。安装后不可出现重复嵌套的两层同名目录。

### 3.2 平台安装或上传


ChatGPT 网页版：上传根目录中的 `ppt-course-notes.zip` 和本次课件，再发送 `调用模板_网页版GPT.md` 中的指令；网页端按本次附件读取 SKILL.md，不是永久安装。

### 3.3 安装验证


检查 `%USERPROFILE%\.codex\skills\ppt-course-notes\SKILL.md` 是否存在，重新打开 Codex，在输入框中选择或输入 `$ppt-course-notes`，并附上一节 PPT 做小范围测试。

## 4. 调用方式


### 4.1 最简调用


```text
$ppt-course-notes 请根据我提供的课程 PPT，按原章节和页码直接在对话中生成完整笔记，不要创建新文件。
```

附上本次课程的 PPT/PDF 或 ZIP，并说明课程名称与本次需要整理的章节。

### 4.2 推荐调用模板


```text
$ppt-course-notes 课程：<课程名>；资料：<已上传PPT/PDF/ZIP>；范围：<本节或全部>；按PPT顺序逐知识点讲定义、性质、公式、推导、原例题、易错点；注明课件来源；只在当前对话框输出，所有原有笔记内容完成后再提供可选补充。
```

### 4.3 不同平台的调用差异


Codex：在已安装环境使用 `$ppt-course-notes`；网页版 ChatGPT：上传 Skill ZIP 和课程资料，明确要求先阅读 ZIP 中 `ppt-course-notes/SKILL.md`，然后直接在聊天输出笔记。

## 5. 输入要求


### 5.1 必需输入


至少有实际可读取的本次课程 PPT/PDF/截图或明确粘贴的课件内容，以及需要整理的章节范围（未指定时按本次全部附件处理）。

### 5.2 可选输入


教师讲课录音转写、配套教材、老师考点说明、过往课程笔记、需要保留的公式符号或代码风格。

### 5.3 支持的文件或数据格式


支持 AI 可读取的 PPTX、PDF、图片和含课件的 ZIP；老式 PPT 需要转换，扫描图与公式需视觉核对；脚本依赖可选安装 `python-pptx`、`python-docx`、`PyMuPDF`。

### 5.4 输入不足时的处理


无法可靠识读的页面或公式应说明文件和页码，继续整理可确认内容，不根据常识伪造未看到的 PPT 原题。

## 6. 输出说明


### 6.1 主要输出


直接输出按章、节、知识点层级组织的中文笔记；每节包含概念/原理、公式条件与步骤、课件原例题、易错点和来源。只在用户明确要求导出时才生成 MD/PDF/ZIP。

### 6.2 输出格式与命名


默认使用 Markdown 标题、公式、代码块与必要表格在对话里呈现；对应章节顺序和课件来源；不在默认模式创建 `课程笔记/` 等新文件。

### 6.3 结果解释与人工复核


依据 PPT 页码清点、原公式与例题逐项核对；扫描页、图像或未执行代码只能标注待核验，不能保证自动识别的绝对正确。

---

## 7. 工作流程与核心规则


### 7.1 工作流程


① 确认本次附件与章节顺序；② 逐页提取并视觉核对公式/插图；③ 按三级标题解释所有关键知识点；④ 完整讲解 PPT 原例题；⑤ 检查漏页、易错条件与来源；⑥ 在聊天中直接交付，最后再列可选扩展。

### 7.2 核心规则


忠实于课件术语与原题；补充内容标明非课件原文；公式写明适用条件与符号；Java/C++ 代码正确换行和缩进；不把内容精简成空泛提纲；优先完成笔记再谈拓展。

### 7.3 异常与失败处理


缺页、乱码、图形或公式无法辨认时明确指出相应位置并继续其他部分；大课件可依次分段输出，不将缺失章节假装完成。

### 7.4 安全、隐私或公平性规则


上传教材、课堂录音或个人笔记前应核对公开权限，避免上传学生隐私、账号和密钥；网页版资料可能由服务端处理，建议最小化上传。

## 8. 已实现能力


### 8.1 核心能力


按 PPT 顺序生成系统化知识点笔记；数学与电路公式推导；Java/C++ 代码说明；PPT 原例题逐步解答；区分讲义来源与 AI 补充；默认聊天直出。

### 8.2 辅助能力


随附来源清点、可选笔记骨架与校验/打包脚本；这些脚本仅为明确要求导出文件的情况提供支持，不负责自动理解课程内容。

### 8.3 多角色或多模式支持


聊天直出为默认模式；只有用户主动明确要求保存文档时，才启用辅助脚本生成文件。

## 10. 脚本与实现说明


### 10.1 主要脚本


`scripts/source_inventory.py` 清点课件；`scripts/scaffold_notes.py` 生成可选文件骨架；`scripts/validate_notes.py` 校验文件结构；`scripts/package_result.py` 打包导出结果。

### 10.2 核心实现思路


以课件为唯一事实基础构建章节和页码对应关系，AI 输出详解，辅助脚本仅做输入索引与静态结构核查。

### 10.3 自动化校验或测试


可独立核对 SKILL.md/引用规则及脚本输入；本次仅完成静态审阅和来源清点，不宣称任何指定学科的笔记正确率。
