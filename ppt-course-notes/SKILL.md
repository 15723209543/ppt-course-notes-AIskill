# PPT 自动生成课程笔记 Skill（v1.1.0）

## 最高优先级：只在当前对话框交付正文
- **默认只在聊天消息内直接输出完整笔记。不得把笔记内容写入新 MD/DOCX/PDF/ZIP，也不得只提供下载链接或文件目录。** 用户明确反向要求导出文件时，才进入可选的文件模式。
- 不因为使用 Codex 就改变输出方式：Codex 的回答消息中展示笔记；网页版同样直接显示笔记。
- **首先完成原有笔记要求**，包括按 PPT 顺序的正文、概念/性质/原理、公式/推导/代码、PPT 原题详解、易错点及来源；补充的学习建议、自测题、结构图、复习计划只能放在主笔记全部完成之后，并标为“可选补充”，不挤占原笔记内容。
- 多课件按老师章节顺序逐章输出，单次可容纳多少就输出多少，较长时在末尾标明已经覆盖的章节/剩余范围；不擅自裁剪为提纲、摘要、待办或生成文件。
- 当用户只要某一章，直接完成该章；用户说“继续下一节”，沿用此前适用规则，避免重复已经讲完的部分。

## 开始前阅读
1. [references/note-rules.md](references/note-rules.md) 知识点写法及数学、代码等学科要求。
2. [references/source-and-coverage.md](references/source-and-coverage.md) 课件来源、图片识读、页码及覆盖追踪。
3. [references/output-contract.md](references/output-contract.md) **新版聊天输出合同**（旧版生成文件为默认的条款已失效）。
4. [references/dialog-delivery.md](references/dialog-delivery.md) 章节分段回复、附录放置及可选增强顺序。
5. 需要示范时读取 [assets/note.template.md](assets/note.template.md)、[references/prompt-templates.md](references/prompt-templates.md)。

## 输入、证据及顺序
- 读取本次用户的 PPTX、PDF、截图、ZIP、指定教材、课堂录音转写、已有笔记及教师要求；先确认能够实际访问的内容，不能从文件名或模型记忆补造课件知识。
- 课件是任务基础：尊重课件术语、组织和原题；教师要求、本次用户明确限定的章节与答题格式优先于通用规则。补充外部知识时标 `【补充说明，非课件原文】`。
- 视觉核对公式、图表、电路、程序输出、扫描页。没看清的符号或数字明确标为待核对，其他内容继续完成；绝不凭抽取文字推断图片数据。
- 可以在**必要时**使用脚本做只读来源清点；其产生的临时索引是内部工作材料，不能作为对用户交付的笔记文件，也不能因脚本存在而改用文件输出。

## 必须完成的原有笔记内容
对每一主要知识点，在合理的情况下依次包含：
1. 大标题按课件章、节与知识点三级层次组织；标明实际来源文件与 PPT 第N页。
2. 概念定义、术语、作用、典型背景，以及与前后知识点的联系。
3. 全部重要性质、定理、条件、公式、符号、单位与适用边界；必要推导不跳关键步骤。
4. “怎么使用”：计算步骤、证明思路、程序调用方法或解题判断流程。
5. 课件里的原始例题：完整题意、分析、逐步解答、必要验算与规范结论；新增例题明确是自编。
6. 易错、易混、易漏前提及特殊情况，说明错误原因与正确写法；知识点末尾可加简洁速记。
7. 本节结束列出**本次课件实际涉及**的重点与疑义，不自动把不在 PPT 的难题硬塞进笔记。

### 课程差异
- 数学、概率论、离散数学、电路：原样保留符号与条件、推导过程、公式编号、必要的电路/关系示意；有序对按源材料或用户要求写 `⟨x,y⟩`。
- Java/C++：IDE 风格代码块、正确缩进、分号换行、`@Override` 独立行、说明关键语句作用；代码若只是静态分析，不宣称运行通过。
- 理论课程：完整概念比较、适用边界、重要结论与课件案例，避免空泛口号。

## 检查与交付
- 回复前检查有没有跳过页上的公式、题目、表格、图示，是否把原 PPT 题说成自编，是否错误混淆 PPT 页码、教材页码和 PDF 打印页码。
- **最终输出就是聊天中的笔记正文**。不自行执行 `scaffold_notes.py`、`validate_notes.py`、`package_result.py`：这些是用户日后**明确提出导出文件**时才启用的可选脚本。
- 用户原本要求的正式笔记完成后，可以用一小节列出“可选后续补充：知识点结构图、自测题、增量更新”等，不能以建议代替原本应输出的笔记。

## 跨平台
- Codex：将**本 SKILL.md 所在的同名文件夹**安装至 `~/.codex/skills/ppt-course-notes`，在包含本次课件的项目里使用 `$ppt-course-notes`。
- 网页版：上传 `ppt-course-notes.zip` 与本次课件，要求读取本 ZIP 内的 `ppt-course-notes/SKILL.md`，执行“聊天直出”合同；无法运行 Python 也须按同一内容规则直接回答。
- 发送指令见包装目录 `调用模板_Codex.md`、`调用模板_网页版GPT.md`；Skill 内引用 `references/prompt-templates.md`。
