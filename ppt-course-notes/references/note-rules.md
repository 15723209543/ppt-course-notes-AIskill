# 笔记正文标准（强制）

## 一、章节结构

- 标题 `# 第N章 章节名称`；二级标题以 PPT 的主题划分；三级标题是可独立复习的最小知识点。
- 用完整中文句子讲解，原则上不要只有关键词。可用表格整理可比项目，避免长段堆砌。
- 每个知识点一般采用：`定义/概念 → 作用与背景 → 性质、规律与公式 → 怎么用/推导 → 例题 → 易错点 → 小结`。不适用的项目不机械塞入。
- 标记 **重点**、**易错**、**补充**，优先遵守教师明确强调的范围；不要凭经验宣称某题必考。

## 二、原题、推导与公式

- PPT 原题要完整誊录，包括题干、图表数据、选项、已知条件；无法辨认时标注具体源页和缺失项。
- 公式使用 LaTeX，提供变量定义、单位、成立条件、常见误用；逐步解释推导中的代换、法则。
- 测验解题要写方法选取理由、每一步计算、最终答案和必要验算；不因答案已知而倒推编造过程。
- 课件中定义、定理、教材编号能明确读到时保留原编号；不确认时不写“定理3.2”。

## 三、代码与编程内容

```java
@Override
public void run() {
    // 记录当前线程开始运行；与教材示例功能对应
    System.out.println("running");
}
```

- 程序代码应逐句或分逻辑块解释“完成了什么、为什么这样写”，并给出参数/返回值/副作用/异常/边界情况。
- 语法未必可在任意 IDE 运行，若依赖 Swing/文件/网络/库，清楚交代前置条件，不写未经测试的“运行成功”。

## 四、来源标记和三种页码

- `【来源：第2章 正弦交流电路.pptx｜第13页】` 代表 PPT 第13张幻灯片（从1开始）。
- `【教材：第88页】` 只能在有可靠教材对应信息时出现。
- `【打印版：第12页】` 只能在最终排版渲染后出现，不得用 Markdown 段落顺序猜测 A4 页码。
- 同知识点跨课件时标多个来源；整章引用只能作为导航，不能替代最小知识点引用。

## 五、排版

- 不产生空白图框；不能自动制作图时用 `【待补图：源文件｜第N页，原因】` 代替。
- 笔记习惯偏向细致而非省略，应覆盖内容广度和可理解性；不同课程根据性质调整例题比例。
- 章节末附 `本章核心结论` 和 `本章易错点清单`；不要求课件每页固定一段。
