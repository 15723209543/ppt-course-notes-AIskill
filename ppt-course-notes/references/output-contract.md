# 输出合同 v1.1：默认聊天直出

## 禁止在默认模式下创建笔记文件
- 当前用户明确指定 **PPT 笔记在聊天对话框直接完整生成**，不要额外创建 `.md/.pdf/.docx/.zip` 等笔记成品。
- 即使课件超过一章，也应在本次可容纳的回答中逐章展开、在末尾说明实际覆盖范围；不可自作主张以一个下载包代替正文。
- 默认只输出：标题/三级知识点、概念、原理、推导、步骤、原始例题详解、易错点、来源标注、每章总结、待核对处。
- 如果用户已明确要求纯文本而不是 Markdown，也照做。

## 聊天内示例层次
`# 第X章 xxx` → `## X.1 xxx` → `### X.1.1 xxx` → 正文 → `【来源：原文件.pptx｜第n页】`。
- PPT 页码必须是可核对的页号，不造教材页码、不造 A4 打印页码。
- 数学排版使用标准 LaTeX；代码块注明语言并正常缩进；重要表格和例题完整列出。

## 例外：用户明确要求文件时
可使用 `scripts/scaffold_notes.py / validate_notes.py / package_result.py`，生成 Markdown / PDF / ZIP；但**不能把例外变成默认行为**。文件导出中仍必须保持原有的逐页证据核对，且生成文件不能污染 Skill 本身。
