# 笔记直接在对话中输出

1. 用户只上传一节或说“继续下一章”时直接交付该节完整笔记，勿输出空模板或文件结构。
2. 若资料齐全，将章节标题、考点、公式、原 PPT 例题按顺序输出；用能独立理解的详解而非关键词罗列。
3. 避免每张幻灯片机械重复；相同概念可合并说明，旁边保留每个相关页码。
4. 一次回复无法容纳全学期内容时，优先完整写完最先的章节，不压缩为短提纲；明确已完成边界与后续待写范围。
5. 先按原定格式完成**全部核心笔记**，再提供任何可选增强。建议的自测题、复习联动、插图提取不应成为强制部分，也不得覆盖用户指定的原有结构。
6. 不记录学生身份、作业成绩或课程私人材料到 Skill 模板。
